## 🛠️ तंत्रज्ञान (Strict Technology Stack)

हा प्रकल्प केवळ **क्लायंट-साइड फ्रंट-एंड** तंत्रज्ञानावर विकसित करण्यात आला आहे:
- **HTML5**: सिमेंटिक रचना, Open Graph व LocalBusiness Structured Data (JSON-LD).
- **CSS3**: व्हॅनिला सीएसएस, रिस्पॉन्सिव्ह ग्रिड/फ्लेक्सबॉक्स, डार्क ग्रीन, गोल्ड आणि रूबी रेड पॅलेट.
- **Vanilla JavaScript (ES6+)**: कोणत्याही लायब्ररी किंवा फ्रेमवर्कशिवाय (No React, No Angular, No Vue).
- **स्थानिक साठवणूक (Storage)**:
  - `localStorage`: शेतीमाल दर, व्यवसाय मजकूर, सेटिंग्ज व भाषा.
  - `IndexedDB` (`RudraTradersDB`): मोठ्या आकाराची छायाचित्रे ब्राउझरमध्ये साठवण्यासाठी.

> [!IMPORTANT]
> **स्थानिक साठवणूक मर्यादा व स्पष्टीकरण (Frontend-Only Storage Notice):**
> हा पूर्णपणे स्टॅटिक (Static Frontend) प्रकल्प आहे. यात कोणतेही पायथन (Python/Flask), नोड (Node.js/Express) किंवा SQL डेटाबेस सर्व्हर नाही.
> ॲडमिन पॅनेलमधून केलेले बदल (उदा. दर, मजकूर किंवा फोटो) **त्याच ब्राउझर आणि डिव्हाइसवर** सेव्ह होतात. ते इंटरनेटवरून इतर वापरकर्त्यांच्या मोबाईलवर आपोआप अपडेट होणार नाहीत, कारण यात केंद्रीय बॅकएंड सर्व्हर नाही.

## 🚀 स्थानिक पातळीवर कसे चालवावे (How to Run Locally)

### पद्धत १: VS Code Live Server द्वारे (Recommended)
1. VS Code मध्ये `rudra_traders` फोल्डर उघडा.
2. Extensions मधून **"Live Server"** (Ritwick Dey) इन्स्टॉल करा.
3. `index.html` वर राइट-क्लिक करा आणि **"Open with Live Server"** निवडा.
4. वेबसाइट आपल्या डीफॉल्ट ब्राउझरमध्ये `http://127.0.0.1:5500/index.html` वर सुरू होईल.

### पद्धत २: थेट ब्राउझरमध्ये उघडणे
- `index.html` फाईलवर डबल-क्लिक करून कोणत्याही आधुनिक वेब ब्राउझरमध्ये (Chrome, Edge, Firefox, Safari) उघडा.

## 🌐 मोफत ऑनलाइन होस्टिंगवर कसे प्रकाशित करावे (Static Deployment)

हा प्रकल्प संपूर्णपणे स्टॅटिक असल्याने खालीलपैकी कोणत्याही मोफत सेवेवर सहज होस्ट करता येतो:

### GitHub Pages:
1. हे फोल्डर GitHub वरील एका नवीन रिपॉझिटरीमध्ये पुश करा.
2. रिपॉझिटरीच्या **Settings > Pages** मध्ये जा.
3. **Branch** मध्ये `main` निवडून सेव्ह करा.
4. काही सेकंदांत आपली वेबसाइट `https://<username>.github.io/<repo-name>/` वर सुरू होईल.

### Netlify / Vercel:
1. [Netlify Drop](https://app.netlify.com/drop) वर जा.
2. संपूर्ण `rudra_traders` फोल्डर ड्रॅग-अँड-ड्रॉप करा.
3. सेकंदांत मोफत लाईव्ह URL मिळेल.
